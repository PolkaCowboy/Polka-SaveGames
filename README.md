# RDR2 Clean Saves 

A series of saves from a playthough where I did as little as possible to interact with the world so I could have a Epilogue save for as much for John to explore as possible. Every radiant NPC quest that can be available for John should be available in this save. 

Copy `SRDR30012 - After Epilogue` into `C:\Users\USERNAME\Documents\Rockstar Games\Red Dead Redemption 2\Profiles\SOMEHEXVALUE` and rename it to `SRDR30012` or some other ending number of the save file you wish to overwrite. 

Save game location may also be located at `C:\Users\USERNAME\OneDrive\Documents\Rockstar Games\Red Dead Redemption 2\Profiles\SOMEHEXVALUE` if OneDrive is enabled
